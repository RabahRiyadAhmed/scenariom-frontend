# UiPlaceholders

## Rôle UI

État visuel temporaire pendant le chargement d'un contenu : lignes, avatar, image, carte ou bloc de texte. Il ne contient pas de donnée métier.

## Options UI

- forme : ligne, cercle, rectangle, image ou carte ;
- dimensions et ratio ;
- ton et contraste ;
- animation : fixe, pulse, glow ou wave ;
- groupe de placeholders pour reproduire une mise en page.

## Personnalisation custom autorisée

Les placeholders peuvent reprendre le rayon, le cadre et la texture discrète du thème. L'animation doit rester légère et désactivable. Un custom ne doit pas afficher de faux texte lisible ni simuler des données réelles.

Exemple : une carte Arcane peut avoir trois lignes brumeuses et une zone image avec une animation pulse violette très douce, tout en gardant les dimensions de la vraie carte.

## À tester

Réduction de mouvement, contraste light/dark, Web/Expo, RTL, tailles d'écran et remplacement propre par le contenu final.
