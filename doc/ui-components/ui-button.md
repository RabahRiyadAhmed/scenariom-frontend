# UiButton

## Actions

- press/click ;
- disabled ;
- loading ;
- icône avant ou après le texte ;
- accessibilité via label.

## Options

`tone`, `variant`, `size`, `rounded`, `fullWidth`, `icon`, `iconPosition`.

## À tester

Chaque ton en clair/sombre, texte long, RTL, clavier Web et press Expo. Un futur bouton SVG doit ajouter son mode de redimensionnement et ses zones sans modifier UiButton.
