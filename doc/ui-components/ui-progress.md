# UiProgress

## Entrées

Valeur bornée 0–100, label, ton, taille, segments, rayures, animation, vertical et remplissage par le haut/bas.

## Actions

Aucune action obligatoire ; la valeur vient de l’état parent et peut évoluer.

## À tester

0, 25, 50, 75, 100, segments, six tailles, vertical Web/Expo, RTL et label traduit. Les styles fixes sont Tailwind/NativeWind ; seuls les pourcentages calculés peuvent être inline.
